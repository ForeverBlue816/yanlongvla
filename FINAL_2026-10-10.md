# Final-stage plan (2026-10-10 → 2026-11-16)

Authoritative for all work after the RAQ-FT v2 gate pass (E092). Supersedes the promotion/final-deployment paragraphs of `PLUSTRAIN_2026-10-08.md` and `ADDENDUM_2026-10-07.md` item 4 where they differ.

**Candidate frozen:** RAQ-FT v2 2-bit backbone (LIBERO-256 calibration, 768 updates, per-group learning rates) + uniform M2 (2-bit) expert + A8. **Amendment:** INT8 KV cache is dropped from the deployable configuration; the KV cache (≈15 MB) stays BF16 and the A8-KV row is reported only as an appendix feasibility note. W2A8 = 2-bit weight storage, INT8 activations and INT8 decoded weights for GEMM; attention internals in BF16. The frozen candidate is `raqft_a_2bit` (739/1000, +3.5 pp [+0.49, +6.69] vs original 2-bit); the composed deployable row is `a8_raqft`.

## F4. Deployment (Oct 19 – Nov 2, with Ethan)

INT8-grid codebook variant of the final RAQ-FT (STE on codebook entries, two-codebook sum in [−127, 127]), one Plus run for parity. Backbone decoded once to persistent INT8 weights; prefill via W8A8 GEMM (per-row weight scale, per-token activation scale); expert kept at 2-bit storage with fused decode-to-INT8 GEMV. Measured on L40S: prefill latency, expert per-step latency, end-to-end, peak memory; Jetson Orin if available. Report storage (GB), runtime memory, bytes read per inference.
