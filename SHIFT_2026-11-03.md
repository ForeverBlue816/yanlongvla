## Specification (user, verbatim)

> Shift-aware quantization track (2026-11-03). This is the only new work; let V0 / V1 finish their queued Plus runs and start nothing else. Pre-register in SHIFT_2026-11-03.md before the first job.
>
> ## 0. Hypothesis
> The calibration set contains unperturbed frames only. Layer-wise quantization minimizes tr(ΔW H ΔWᵀ) with H estimated on that set and hides error in directions that matter under the LIBERO-Plus perturbations. We replace H by a shift-aware metric H_rob = H + λ·Σ_shift, where Σ_shift is the second moment of activation differences under input perturbations that are NOT the test perturbations.
>
> ## 1. Shift statistics (GR00T, backbone + four heads; same 256 calibration observations)
> For each calibration observation x and k = 4 perturbed copies x'_j:
>   - photometric: brightness ±20%, contrast ±20%, hue ±5°, Gaussian blur σ∈[0.5,1.0], applied to both camera views;
>   - geometric: random resized crop keeping 90–95% of the image, re-resized to the model input;
>   - on-policy: 1 state per observation taken from a rollout of the current 2-bit TCQ base (tcq_w2_rht) on the same task, at a random step within the first 40% of the episode, unperturbed environment.
>   No camera-pose or robot-initial-state perturbations anywhere in calibration (these are the test perturbations).
>   Per quantized Linear layer l, accumulate in FP64:
>     H_l      = E[x xᵀ]  (as now)
>     Σ_shift,l = E_j[(x'_j − x)(x'_j − x)ᵀ]  over all observations, tokens and perturbed copies, with x and x'_j token-aligned (same token position; for on-policy states use the state's own activations as x' and the calibration activation of the same task/phase as x, or treat them as additional samples of H only — record which).
>   Report per module: tr(Σ_shift)/tr(H), and the top-5 eigenvalue share of Σ_shift (is the shift low-rank?).
>
> ## 2. Robust metric and λ (fixed rule, not tuned on Plus)
>   H_rob,l = H_l + λ_l · Σ_shift,l,  λ_l = tr(H_l) / tr(Σ_shift,l)   (equal-trace rule, per layer).
>   Control arm: H_iso,l = H_l + λ'_l · I with λ'_l = tr(H_l)/d_in (same total trace added, isotropic).
>   Keep the 1% mean-diagonal damping on top in all arms, as in the base.
>
> ## 3. Arms (TCQ, two-sided RHT, 1 Viterbi pass, same tlut/row-scale WLS, same seeds)
>   A  tcq_w2_rht           — existing base (559), no refit.
>   B  tcq_w2_rht_iso       — H_iso.
>   C  tcq_w2_rht_shift     — H_rob.
>   Byte-identical payloads across arms (check). Per-layer: relative weight error, calibration H-error, and the error under Σ_shift, for all three arms (table by module).
>
> ## 4. Evaluation (PTQ level, before any fine-tune)
>   Held-out action MSE on the 256 held-out observations AND on their perturbed copies (same recipe as §1, different seed).
>   Plus selection 1000 for B and C, paired vs A, FP 618, B2 556; report camera-viewpoint and robot-initial-state halves separately.
>   LIBERO medium 1000 for C only (in-distribution check; it must not drop by more than 2 pp vs A, else the arm is reported as a trade-off, not a gain).
>   Reading (fixed now): C is adopted into the base if C − A on Plus selection has 95% CI lower bound > 0; if B matches C, the result is "damping suffices" and is reported as such; if neither beats A, the track is closed and reported in the analysis section as a negative result with the shift statistics.
>
> ## 5. If C passes
>   Refit π₀.₅ with the same recipe (its own Σ_shift), Plus selection 1000 vs 704 / 765. Then the fine-tune on arm C with the readout loss plus a shift anchor μ·Σ_l tr(ΔW_l Σ_shift,l ΔW_lᵀ)/‖W_l‖², μ set so the anchor is 10% of the initial loss; this is a later step and is not started before §4 is read.

## Pre-registration (agent, 2026-11-03, before the first job)

### Perturbed copies (§1)
k = 4 copies per calibration observation: **j = 1, 2 photometric, j = 3 geometric, j = 4 on-policy**. Generator
`numpy.random.default_rng(SeedSequence([20261103, 0, i, j]))` for calibration observation i (stream 0); the held-out copies of §4 use
stream 1 (`SeedSequence([20261103, 1, i, j])`), so no calibration copy is reused for evaluation. One parameter draw per copy is applied
identically to both camera views (agent view and wrist), on the 256 × 256 uint8 frames the bridge receives.
- **Photometric** (all four in this order, each with its own draw): brightness factor U[0.8, 1.2] (PIL `ImageEnhance.Brightness`),
  contrast factor U[0.8, 1.2] (`ImageEnhance.Contrast`), hue shift U[−5°, +5°] (rotation of H in HSV), Gaussian blur σ U[0.5, 1.0]
  (PIL `GaussianBlur(radius=σ)`).
- **Geometric**: square crop with area fraction U[0.90, 0.95] (side √a·256, rounded), top-left uniform over the valid range, bilinear
  resize back to 256 × 256.
- **On-policy**: one rollout per calibration observation i of its own LIBERO task (suite from `calibration_suites.json`, task id by
  exact match of the prompt to the suite's task language) with the 2-bit base `tcq_w2_rht` through the standard bridge/LIBERO client
  (seed 7, 10 settle steps, suite step limits, 8 of 16 actions executed per call, unperturbed environment). Initial state: LIBERO
  init state 25 + (r mod 25) where r counts the calibration observations of that task in manifest order — states 25–49, never the
  0–24 used by LIBERO medium. The whole episode is recorded at every policy call; the captured state is a policy call drawn uniformly
  among the first ⌈0.4·C⌉ calls of the C calls of that rollout (rng stream 0, j = 4). **Pairing (the spec's first option, recorded):**
  x' = the captured state's own activations, x = the clean activation of the calibration observation of the same task whose phase is
  nearest (phase of x = frame index / episode length in the dataset; phase of x' = executed steps before the call / steps of the
  rollout excluding settle). The pair, both phases and the rollout outcome are logged per observation. Token alignment holds by
  construction (same prompt, same image sizes, same 8-d state); every hooked call asserts equal shapes and is counted, any mismatch
  is skipped and reported.
- No camera-pose and no robot-initial-state perturbation enters calibration.

### Accumulation (§1)
Same hooks, same 432 quantized Linear layers and the same forward passes as the base calibration (`groot_ptq._calibrate`: full policy
inference through each suite's FP checkpoint; backbone from libero_spatial, every head through its own suite; DiT layers over all 4
flow steps); every copy x'_j runs with the same flow-noise seed as its x. Per hooked call, the token-aligned difference d = x' − x is
formed in FP32 and dᵀd (FP32 GEMM) is added into an **FP64 accumulator**; Σ_shift,l = accumulated sum / number of (token, copy)
pairs. Per layer also the per-copy-type traces (photometric / geometric / on-policy), so the on-policy share can be separated.
**H_l is the base's existing E[x xᵀ]** (same 256 observations, same passes; FP32 accumulation as in the base) — not re-accumulated,
so that arm A stays the existing fit and the arms differ only in the added term. Σ_shift is stored per layer in FP32
(`OUT/groot/shift/sigma/<key>/<layer>.pt`). Reported per module (vision qkv / proj / fc1 / fc2, LLM q / k / v / o / gate / up / down,
vl_self_attention q / k / v / o / ff0 / ff2, DiT q / k / v / o / ff0 / ff2): mean and range of tr(Σ_shift)/tr(H), the top-5
eigenvalue share of Σ_shift (`eigvalsh`, FP32), and the share of each copy type.

### Metrics and fit (§2–§3)
H_rob,l = H_l + λ_l Σ_shift,l with λ_l = tr(H_l)/tr(Σ_shift,l); H_iso,l = H_l + (tr(H_l)/d_in) I. Both add exactly tr(H_l), so
tr(H_rob) = tr(H_iso) = 2 tr(H). **Damping**: `groot_tcq.fit_layer` normalises the (rotated) metric by its mean diagonal and adds
the relative damping; the base uses 0.01 on H. To keep the base's absolute damping (1 % of H's mean diagonal) in arms B and C, whose
metric has twice H's mean diagonal, the relative ladder is 0.005 → 0.05 → 0.5 (= 1 % / 10 % / 100 % of H's mean diagonal); recorded per
layer. Everything else as `tcq_w2_rht`: two-sided randomized Hadamard (same per-layer seeds), 1 LDLQ/Viterbi pass, QTIP engine
e90c668, tlut init and per-layer WLS, per-row WLS scale — both WLS steps under the arm's metric (that is the arm). Fit keys
`backbone_tcq_rht_iso`, `head_tcq_rht_iso_<suite>`, `backbone_tcq_rht_shift`, `head_tcq_rht_shift_<suite>`; rows `tcq_w2_rht_iso`,
`tcq_w2_rht_shift`. Payload check: per-layer `payload_bytes` and assembled `linear_payload_bytes` must equal arm A's exactly.
Per-layer table (`groot_shift.py --stage errors`): relative weight error ‖ΔW‖²/‖W‖², calibration H-error tr(ΔW H ΔWᵀ)/tr(W H Wᵀ),
Σ-error tr(ΔW Σ ΔWᵀ)/tr(W Σ Wᵀ), for A, B, C, summarised by module.

### Evaluation (§4)
- **Held-out action MSE** vs FP (`groot_shift.py --stage offline`, same device for all rows): the 256 held-out observations
  through the libero_spatial checkpoint (as `groot_offline`), `torch.manual_seed(i)` per observation, clean and **3 perturbed copies
  per observation (2 photometric + 1 geometric, stream 1)**; on-policy copies do not exist for held-out frames. Rows FP, A, B, C;
  each perturbed copy compares the row with FP on the same perturbed input.
- **Plus selection 1000** for B and C (`plustrain_groot.py --stage plus`), paired (`baselines/paired_stats.py`) vs A
  (`groot_n17_tcq_w2_rht`, 559), FP 618, B2 556, with the camera-viewpoint and robot-initial-state halves.
- **LIBERO medium 1000** for C. *Deviation, recorded:* A has no LIBERO medium run, and the rule compares C with A, so A's medium
  1000 is run as well (same protocol, same GPU type where possible); it is the reference of the rule, not a new arm.
- **Reading (fixed now, the user's rule made operational):**
  - C adopted into the base iff the paired C − A on Plus selection has 95 % CI lower bound > 0 and LIBERO medium C ≥ A − 2 pp
    (if C − A passes on Plus but medium drops by more than 2 pp: "trade-off, not a gain").
  - "B matches C": B − A also has CI lower bound > 0 and the paired C − B CI contains 0 → reported as "damping suffices".
    If C passes and C − B has CI lower bound > 0 → shift-aware gain over isotropic damping.
  - Neither C − A nor B − A with CI lower bound > 0 → track closed, negative result in the analysis section with the shift statistics.
  - B passes and C does not → reported as an isotropic-damping effect; C not adopted.
- §5 (π₀.₅ refit, shift-anchored fine-tune) is not started before §4 is read.

Reading of the statistics (descriptive, before any fit): (i) the shift second moment is 3–60 % of H's trace — smallest in the DiT
feed-forward input (3 %), largest in the vl_self_attention FFN output projection (59 %); (ii) it is **not low-rank** except in the DiT:
top-5 eigenvalues carry 5–30 % of the trace in the backbone and vl_self_attention (effective rank 20–840), 22–48 % in the DiT inputs;
(iii) in the DiT, **71–85 % of Σ's trace comes from the on-policy pairs**, i.e. from the difference between a policy-visited state and a
phase-matched demonstration frame of the same task, while in the backbone the image perturbations carry about half (photometric 16–31 %,
geometric 22–32 %). One LLM `down_proj` has tr(Σ)/tr(H) ≈ 0 — the layer-2 Hessian-outlier layer, whose tr(H) is dominated by one
input channel; by the equal-trace rule its λ is large and H_rob ≈ 2·(trace-matched) Σ-direction there (recorded, not changed).
