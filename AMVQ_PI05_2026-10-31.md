## Implementation (agent, 2026-10-30 19:40 UTC, recorded before the first job) — `scripts/plustrain_amvq_pi05.py`

| Item | Choice |
|---|---|
| G (stage `fisher`) | per layer, diag E[δ²] with δ = ∂⟨v, Ω^{1/2} ε⟩/∂(layer output) summed over the layer's tokens; ε ~ N(0, I) over the (10 × 32) velocity at each of the 10 flow steps, uniform over steps; 8 probes × 256 bank-(a) observations, latent `make_latent(20261005)(100000 + n, 0)`; FP model (`HybridEngine('fp')`, no CUDA graph, TF32 off); FP trajectory held fixed between steps; prefix pass grad-enabled (graph rooted at the first captured input). Accumulated per DoF group (translation 0–2 / rotation 3–5 / gripper 6) with independent probes, so G = Σ_g G^g and the per-row DoF shares are recorded. Layers no gradient reaches (the last LLM block's q/o/MLP) get G = 0 and are listed. Checkpoint every 16 observations. |
| Ω | Ω[t, j] = γ_t · λ_group(j): γ = 1 on the executed window (action tokens 0–4), 0.5 on tokens 5–9, 0 on the padded dims 7–31 (the π₀.₅ analogue of B-AM's executed 1 / rest 0.5 / padded 0). |
| λ_DoF (stage `lambda`) | measured once on FP: λ_d = 1 / E‖J_d‖_F², J_d = ∂(γ^{1/2} v_d)/∂(expert readouts: the 18 pre-W_O attention outputs of the step), Hutchinson in reverse mode with N(0, I) tangents on the group's velocity entries, 4 probes × 10 steps × 32 calibration observations (B-AM's protocol: 4 × 4 steps × 32). Recorded in `amvq_pi05/lambda.json`. |
| Three-layer Hutchinson check (stage `check`) | first LLM attention, first LLM MLP, first expert layer; 2 calibration observations: the 8-probe Hutchinson G against the exact diag E[δ²] (one backward per weighted velocity entry, 70 entries × 10 steps). Pass iff the relative error of each layer's total Σ_o G_o is < 5 %; the per-row relative L2 error is recorded (8 probes do not resolve single rows to 5 %, the fitter's metric uses the rows jointly). The fit does not start if the check fails. |
| Fit (stage `fit`) | `backbone_vq_fit.fit_backbone` — the base's own fitter (group-wise √F residual weighting in assignment and centroid WLS, both planes, GPTQ-style column feedback with the full layer H) — with F[o, g] = G[o] for every input group, i.e. the Kronecker metric G ⊗ H_in. Weights from `pi05_libero_int8embed`, RHT signs `layer_signs(name)` (asserted equal to the base's), H_in = the base's calibration moments (backbone: `runs/backbone/calibration` owners; expert: `expert_moment_path`, step-mean), 2 × 256 × 8 codebooks, FP16 row scale by the same RMS rule (asserted equal to the base's), the base's mask tensors. Per layer: Hessian relative error, weight MSE and the action-metric error (G-weighted H-error) of the AM-VQ fit and of the base fit, for the record. |
| Assembly | `models/hd_srvq_amvq_pi05` = the base checkpoint (`hd_srvq_bb_M2_ae_M2_fp32`) with the 414 codebooks + codes replaced; row scales, signs, masks unchanged (asserted); payload asserted byte-identical → linear bpw 2.0201, whole-model 2.9226. |
| Offline (stage `offline`) | 256 held-out observations: relative action MSE (total, per DoF) and readout error for the Fisher base (704 row), the plain base (`story_plain_bb_M2_ae_M2_fp32`, 702 row) and amvq_pi05, one job, one GPU; no gate. |
| Rollouts | PTQ Plus selection 1000 of `amvq_pi05` (guard + `plustrain_run.py`), paired vs base 704 / plain 702 / FP 765 (`baselines/paired_stats.py`). Then the controller: `raqft_studentq_amvq` (frozen `plustrain_raqft.py`, queries = student, bank a, 768 updates) → its Plus (vs 749) → `a8_studentq_amvq` A8 offline → Plus (vs 741) → added 1000 (confirmation) by hand. |
| GPU | one model for everything: RTX 6000 Ada (fit job on rose + killable copy, both pinned to 6000 Ada; Plus / fine-tune / A8 likewise). Recorded per stage. |
| Reading | fixed as in §4 of the spec; the four-base table (plain / Fisher / H5a / K-FAC) goes into the analysis section either way. |

Budget estimate note: the frozen raqft_studentq recipe takes ≈ 9 h on a 6000 Ada (job 197014), not 1.5 h; actuals are reported below.
