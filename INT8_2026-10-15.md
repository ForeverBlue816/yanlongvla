# INT8 deployment track (2026-10-15), runs on the fitting/profiling GPUs, no Plus rollouts

User instruction, recorded verbatim (2026-10-15):

Goal: replace the fake-quant A8 path with real INT8 kernels for the frozen W2A8 row and measure accuracy parity, latency and memory.

1. INT8-grid codebooks (exactness): re-run the final RAQ-FT with codebook entries constrained to the integer grid (STE) and the two-codebook sum clamped to [−127, 127]; per-row scale FP16. Confirm held-out action MSE vs the FP16-codebook W2A8 is within 1e-5 and run one Plus selection-subset check (expect within noise). From here on, decoded weights are exact INT8.
2. Backbone path (compute-bound): decode the 2-bit backbone once at load into persistent INT8 weights (report resident bytes). Run all backbone linear layers with INT8×INT8 GEMM (cuBLASLt or torch._int_mm) using per-row weight scales and per-token activation scales; Hadamard transform applied on the activation side before quantization; softmax, QKᵀ, norms, residual adds in BF16. Verify actions match the fake-quant W2A8 path (max abs diff reported on 256 observations).
3. Expert path (bandwidth-bound), two variants, both measured: (a) INT8-resident expert, same W8A8 GEMM as the backbone; (b) 2-bit-resident expert with a fused decode→INT8 + GEMM kernel for M = 10 tokens (start from the AQLM/VPTQ kernels; decode each 8-weight group once per call and reuse across the 10 tokens). If (b) is not working within 3 days, report (a) only and state it.
4. Measurements on L40S (CUDA graphs on, batch 1, 100 warm inferences, median and p95): prefill latency (vision + language), expert per-step latency, end-to-end for 10 steps and 2 steps, peak and resident GPU memory. Rows: BF16 original; W2A8 with expert (a); W2A8 with expert (b). Same on Jetson Orin if Ethan has one; otherwise state it.
5. Report: a single efficiency table (storage, resident memory, prefill ms, expert ms/step, end-to-end ms at 10 and 2 steps, speedup vs BF16) plus the parity check. No analytic bytes-read numbers in this table; keep those in the appendix with the method stated.
